Tunnell's criterion, in your browser

Is n the area of a right triangle with rational sides? For a squarefree n, Tunnell (1983) turned this ancient question into counting integer points on two ellipsoids. This page runs that count with a Lean 4 function — the same code the Lean kernel evaluates in its checks — compiled for the browser with lean-vir.

What the answer means

For odd n, A and B count the integer solutions of 2x² + y² + 32z² = n and 2x² + y² + 8z² = n; for even n = 2m, C and D do the same with 4x² and m.

If 2A ≠ B, n is not congruent. This direction of Tunnell's theorem is unconditional.

If 2A = B, n is congruent provided the Birch–Swinnerton-Dyer conjecture holds for the curve y² = x³ − n²x. Nobody has proved that converse in general; this page does not claim it.

What is machine-checked: the Lean kernel evaluates this very function on n = 1, 2, 3 (criterion fails) and 5, 6, 7 (criterion holds). What is tested: on every n ≤ 10,000 the WebAssembly build's counts equal native Lean and an independent count (in a browser, every n ≤ 400), and the squarefree n that pass are exactly the terms of OEIS A003273. Tunnell's theorem itself is not formalized here.
